---

## 1. 제품 개요

게임 서비스 및 라이브 운영 PM을 위한 **게임 PM 릴리즈/패치노트 자동화 보조 툴**이다.

게임 기획서, 시스템 문서, 캐릭터/스킬 기획서, BM 기획서, 이벤트 기획서, 회의록, 패치노트 등 분산된 문서를 한 곳에 수집·저장·검색하고, 변경 이력을 자동 추적하며, 승인된 변경사항을 기반으로 패치노트 초안을 생성하는 PM 전용 내부 툴이다.

**핵심 전제:** 사용자가 문서를 직접 정제하지 않아도 등록 가능해야 한다. 직접 정제해야만 등록 가능한 구조는 이 툴의 존재 이유를 약화시킨다.

---

## 2. 핵심 Pain Point

| # | 현재 문제 | 영향 |
|---|---|---|
| P1 | 기획서가 이메일·드라이브·슬랙·위키에 분산 | 최신 문서 찾는 데 시간 낭비 |
| P2 | 업로드 순서 ≠ 최신 문서. 이전 버전이 덮어씌워짐 | 오래된 기획서 기반으로 작업 |
| P3 | 패치노트를 매번 기획서를 뒤져 수동 작성 | 릴리즈 전 패치노트 작성에 1-2시간+ |
| P4 | 변경사항이 어떤 기획서에서 왔는지 추적 불가 | 리뷰·QA에서 맥락 공유 어려움 |
| P5 | 기획서를 정제해서 넣어야 하는 툴은 오히려 업무 추가 | 도구가 짐이 됨 |

---

## 3. 핵심 가치 제안

```
원본 그대로 올리면 → 자동으로 정리되고 → 찾을 수 있고 → 패치노트까지 만들어진다
```

1. **원본 보존 + 자동 처리:** PDF, PPTX, DOCX, CSV 등을 그대로 업로드하면 시스템이 처리
2. **AI 정제본 직접 Import:** GPT로 미리 정제한 JSON을 붙여넣으면 즉시 등록 가능
3. **게임 도메인 특화 검색:** "파이어볼 스킬 변경 이력", "5월 이벤트 보상 기획" 등 자연어 검색
4. **변경사항 → 패치노트 파이프라인:** 승인된 변경사항 후보를 선택하면 패치노트 초안 자동 생성
5. **API 비용 통제:** 기본은 무료. 유료 API는 명시적 요청 시에만 호출

## 5. 사용자 페르소나

**Primary:** 게임 서비스/라이브 운영 PM
- 릴리즈 전 패치노트 작성 책임자

**Secondary (v2 이후):**

- QA 리드: 패치노트와 기획서 대조 검수
- BM 담당자: BM 기획서 버전 이력 추적

## 6. MVP 범위 요약

**MVP = Phase 1(2주) + Phase 2(1주) + Phase 3(1주) = 총 4주**

> **Patch-First 전략 (CEO Review 결정):** Week 1에 AI Import → ChangeCandidate → 버전 판단 → PatchNote Candidate → PatchNote Draft E2E를 완성하여 핵심 가치를 7일 안에 검증한다. 검색·Review Queue·CRUD·Budget Guard 등 지원 기능은 Week 2로 이동.

| Phase | Week | 핵심 기능 | 결과물 |
|---|---|---|---|
| Phase 1 | Week 1 | AI Import + ChangeCandidate + 버전 판단 + **패치노트 후보/초안 생성 E2E** (규칙 기반 Markdown) | 패치노트 초안 1건 생성 E2E 동작 |
| Phase 1 | Week 2 | 검색 + Review Queue + 문서 CRUD + Budget Guard | 기획서 등록·검색·예산 관리 동작 |
| Phase 2 | Week 3 | Raw Upload Inbox + 텍스트 추출 + 처리 상태 분리 | 원본 파일 그대로 업로드 가능 |
| Phase 3 | Week 4 | Raw Upload → ChangeCandidate 연결 + **AI 초안 고도화** + 기획서 리뷰 결과 저장 + E2E 검증 | MVP 완성 (Raw → Patch까지 일관) |

## 7. Non-Negotiable Requirements (13개)

1. Raw Upload Mode와 AI Pre-Review Import Mode 둘 다 지원
2. 사용자가 문서를 직접 정제해야만 등록 가능한 구조 금지
3. 원본 파일 반드시 보존
4. 업로드 실패와 파싱 실패 분리 관리
5. GPT 정제본 JSON Import는 1차 MVP 핵심
6. 문서 검색 기능은 메인 페이지 핵심 진입점
7. 변경사항 후보는 패치노트 생성의 원천 데이터
8. 패치노트 생성 기능은 1차 MVP 포함
9. 업로드 순서로 최신 문서 판단 금지
10. 기존 Approved/Released 문서 교체는 반드시 사용자 승인
11. 유료 AI API 기본 자동 호출 금지
12. 월 예산 0 설정 시 유료 API 완전 차단
13. 제외 기능은 삭제하지 않고 Backlog로 명확히 이동

## 9. 성공 기준 (MVP 검증 기준)

- AI Import로 실제 기획서 1건 등록 → 검색 → 변경사항 확인 플로우 완료
- 패치노트 초안 1건 생성 (수동 선택 → 카테고리 정렬 → 초안 출력)
- Raw Upload로 PDF 1건 업로드 → 텍스트 추출 → 처리 상태 확인
- 유료 API 월 예산 0 설정 시 API 호출 완전 차단 확인
- 검색 응답 시간 < 500ms (100건 이하 문서 기준)
