# 화면 흐름 (Screen Flow)

**버전:** 1.0  
**작성일:** 2026-05-19

---

## 1. 전체 화면 구조

```
/                       메인 (검색 허브)
├── /docs               문서 목록
│   └── /docs/[id]      문서 상세
│       └── /docs/[id]/versions    버전 이력
├── /import             AI Import
│   └── /import/preview Import 미리보기
├── /upload             Raw Upload Inbox
│   └── /upload/[id]    업로드 항목 상세
├── /review             Review Queue
├── /patch-notes        패치노트 목록
│   ├── /patch-notes/new    새 패치노트 생성
│   └── /patch-notes/[id]   패치노트 상세/편집
└── /settings           설정 (AI API + 예산 통합 단일 페이지)
```

---

## 2. 메인 페이지 (/)

**컨셉:** ChatGPT 첫 화면 — 중앙 검색창이 유일한 진입점

```
┌──────────────────────────────────────────────────────────┐
│  🎮 게임 기획서 DB           [Review(3)] [Upload] [설정]  │
├──────────────────────────────────────────────────────────┤
│                                                          │
│                                                          │
│         게임 기획서, 스킬, 이벤트, 패치노트 검색         │
│   ┌────────────────────────────────────────────────┐    │
│   │ 🔍 "파이어볼 스킬 변경 이력"                     │    │
│   └────────────────────────────────────────────────┘    │
│                                                          │
│   [AI Import] [파일 업로드]  [패치노트 생성]              │
│                                                          │
│  ─────────────────────────────────────────────────────  │
│  최근 문서                                               │
│  ┌─────────────────┐  ┌─────────────────┐              │
│  │ [skill_spec]    │  │ [event_spec]    │              │
│  │ 파이어볼 기획서  │  │ 5월 이벤트 기획 │              │
│  │ approved · v2.3 │  │ draft · v1.0   │              │
│  └─────────────────┘  └─────────────────┘              │
│                                                          │
│  패치노트 후보 대기: 5건    Review 대기: 3건             │
└──────────────────────────────────────────────────────────┘
```

**상태별 동작:**
- 빈 검색어: 최근 문서 10개 + 패치노트 후보 배지 + Review Queue 배지
- 타이핑 시: 실시간 검색 결과 (debounce 300ms)
- 엔터: 전체 검색 결과 페이지

## 6. Import 미리보기 페이지 (/import/preview)

```
┌──────────────────────────────────────────────────────────┐
│  Import 미리보기                    [취소] [승인 및 저장] │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ⚠️ Review 필요 항목 2건  ──────────────────────────   │
│  • version_date: 날짜를 인식할 수 없습니다               │
│  • category: 분류 불확실 (제안: "전투 시스템")           │
│                                                          │
│  📄 문서 정보 ────────────────────────────────────────   │
│  제목:     파이어볼 스킬 기획서        [편집]            │
│  유형:     skill_spec                  [변경 ▼]          │
│  카테고리: 전투 시스템 > 마법사 스킬   [편집]            │
│  버전:     v2.3                        [편집]            │
│  날짜:     2026-05-18                  [편집]            │
│  상태:     draft                       [변경 ▼]          │
│  태그:     [마법사] [스킬] [전투] [+ 추가]              │
│                                                          │
│  📋 기획 항목 (3건) ─────────────────────────────────   │
│  • 파이어볼 (skill)   피해량 100%, 쿨다운 8초...  [편집] │
│  • 마나 소비 (resource) 마나 소비 60포인트        [편집] │
│  • 사거리 (range)     최대 사거리 8m              [편집] │
│                                                          │
│  🔄 변경사항 후보 (2건) ─────────────────────────────   │
│  ✅ [modify] 파이어볼 피해량 120% → 100%                │
│     패치노트 초안: "파이어볼: 피해량이 조정되었습니다"   │
│  ✅ [add] 쿨다운 감소 아이템 추가                       │
│                                                          │
│  📝 패치노트 후보 (1건) ─────────────────────────────   │
│  ☑ [balance] 파이어볼: 피해량이 120%에서 100%로 조정    │
│                                                          │
│  ─────────────────────────────────────────────────────  │
│                      [취소] [승인 및 저장 ✓]            │
└──────────────────────────────────────────────────────────┘
```

**[B1] 승인 및 저장 처리 흐름:**
1. 편집된 데이터 서버 재검증 (Zod Schema)
2. DocumentVersion + NormalizedDocument + DesignItem DB 저장
3. ChangeCandidate 전체 → review_status = **approved** 일괄 저장 (pending → approved)
4. 저장 완료 후 안내:
   - "문서가 등록되었습니다." + **[패치노트 생성하기 →]** 버튼 표시
   - 버튼 클릭 시 `/patch-notes/new`로 이동 (해당 문서의 approved 변경사항 자동 필터링)

| Empty State | 문서 0건 | "AI Import로 첫 문서를 등록하세요" 안내 |
| Loading | API 응답 대기 | Skeleton UI |
| Error | API 실패 | 에러 메시지 + 재시도 버튼 |
| Partial | 부분 성공 | 경고 배지 + 상세 설명 |
| Budget Locked | API 예산 초과 | 배너 경고, API 버튼 비활성화 |
